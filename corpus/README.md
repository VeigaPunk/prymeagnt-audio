# audio — domain corpus

Reference corpus of the **audio** shokunin lane: the craft master's notebook
for game SFX and soundtrack production — synthesis (sox/ffmpeg), layering,
mixing, loop seams, adaptive stems — verified by headless analysis
(duration, loudness, spectral content, seam continuity). "Sounds good" is
not a verdict; a measurable proxy is.

Purposes: (1) reference guide — every artifact carries its counting command;
(2) discovery corpus for new sound/music moves; (3) inspiration source —
failed synthesis attempts stay in the ledger with their measurements.

Provenance: seeded at mint 2026-10-12 (host toolchain census + production
checklist). Round history will accumulate on craft/* branches of this repo;
ledger in .shokunin/MANIFEST.json there.

Upstream: https://github.com/VeigaPunk/prymeagnt-audio — local execution
references it with: git fetch audio main
